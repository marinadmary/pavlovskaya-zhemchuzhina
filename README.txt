ТСН «Павловская Жемчужина» — прототип сайта, версия 3

КАК ПОСМОТРЕТЬ
1. Распакуйте архив.
2. Откройте файл index.html двойным щелчком.
3. Сайт откроется в браузере и будет работать локально без установки программ.

КАК ОБНОВИТЬ НОВОСТИ
1. Откройте файл script.js в Блокноте.
2. В самом верху находится блок const news = [...].
3. Скопируйте одну запись и поменяйте дату, заголовок, текст и тег.
4. Новую запись ставьте первой.
5. Сохраните файл и обновите страницу в браузере.

ВАЖНО
- Для QR-кода Max нужна точная ссылка на официальный канал.
- Файлы в разделе «Документы» пока не подключены.
- Форма обратной связи сейчас демонстрационная и не отправляет данные.
- Домен p-zh.ru можно подключить позже, когда появится доступ к DNS. Переделывать сайт не потребуется.
