ТСН «Павловская Жемчужина» — сайт для жителей

СОДЕРЖАНИЕ
- index.html — главная страница сайта
- styles.css — стили и адаптивная версия
- script.js — новости, FAQ и интерактивные элементы
- assets/ — фотографии, логотипы, QR-коды, карта, документы и формы

КАК ПОСМОТРЕТЬ САЙТ ЛОКАЛЬНО
1. Откройте файл index.html двойным щелчком.
2. Сайт откроется в браузере.
3. Для проверки мобильной версии в Chrome нажмите F12 → Ctrl+Shift+M.

ПУБЛИКАЦИЯ
Сайт публикуется через GitHub Pages из ветки main и папки /(root).
Для обновления сайта новый репозиторий создавать не нужно.

КАК ОБНОВИТЬ САЙТ
1. Откройте репозиторий pavlovskaya-zhemchuzhina на GitHub.
2. Нажмите Add file → Upload files.
3. Загрузите изменённые файлы поверх существующих.
4. Нажмите Commit changes.
5. GitHub Pages автоматически обновит сайт через несколько минут.

ЧТО МЕНЯТЬ
- Новости: script.js
- Тексты и блоки страницы: index.html
- Дизайн и мобильное отображение: styles.css
- Фото, QR-коды и документы: папка assets

КАК ДОБАВИТЬ НОВОСТЬ
В начале файла script.js находится массив const news = [...].
Новую запись добавляйте первой.

Для новости можно указать:
- date — дата
- title — заголовок
- text — короткий текст
- tag — категория
- image — путь к фотографии, если она используется
