ТСН «Павловская Жемчужина» — сайт для жителей

СОДЕРЖАНИЕ
- index.html — структура и тексты страницы
- styles.css — дизайн и мобильная версия
- script.js — новости, FAQ и интерактивные элементы
- assets/ — фотографии, карта, документы, QR-коды и логотипы

КАК ОБНОВИТЬ САЙТ НА GITHUB
1. Откройте репозиторий pavlovskaya-zhemchuzhina.
2. Нажмите Add file → Upload files.
3. Загрузите изменённые файлы поверх существующих.
4. Нажмите Commit changes.
5. GitHub Pages автоматически опубликует изменения.

КАК ДОБАВИТЬ НОВОСТЬ
В начале script.js находится массив const news = [...]. Новую запись добавляйте первой.
Поля новости: date, title, text, tag. Для фотоновости добавьте images: ['assets/имя-файла.jpg', ...].
Фото предварительно загрузите в assets.
